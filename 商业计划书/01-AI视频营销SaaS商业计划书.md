# AI 视频营销 SaaS 商业计划书（完整版）

## 项目名称

**Seedance Studio Pro** —— AI 短视频批量生成与营销 SaaS 平台

---

## 一、项目概述

### 1.1 一句话描述

面向电商卖家的 AI 短视频批量生成工具，把商品链接变成可直接投放的营销视频，实现 "1 人管 100 个账号" 的内容产能。

### 1.2 解决的问题

- 电商卖家需要大量视频投放（抖音、TikTok、快手、视频号），但拍摄成本高、周期长
- 一个 SKU 需要 3-5 条不同风格的视频去测试转化率，人工根本做不过来
- 中小卖家雇不起专业视频团队（一个剪辑月薪 8K+，月产 30-50 条）
- AI 视频工具很多，但没有专门为"卖货"优化的

### 1.3 核心价值主张

> 上传商品图/链接 → AI 自动生成 10 条带货视频 → 一键分发到 5 个平台 → 数据回传优化迭代

### 1.4 项目基础

已有 Seedance Studio 种子代码（2869 行完整 SPA），包含：
- AI 视频生成引擎（文本转视频 / 图片转视频）
- 批量生成工作台（多场景并发、角色库、模板库）
- 用户认证与积分系统
- 历史记录管理

## 二、市场分析

### 2.1 市场规模

| 维度 | 数据 |
|------|------|
| 中国电商卖家数量 | 2000 万+（淘宝 1000 万+，抖音小店 500 万+，拼多多 300 万+） |
| 中国短视频营销市场规模 | 2026 年约 4000 亿元 |
| 需要视频内容的卖家比例 | 70%+（抖音/快手/视频号卖家 100% 需要） |
| 月均视频需求量（中小卖家） | 30-100 条 |
| AI 视频工具渗透率 | < 5%（2026 年，大量卖家仍手工做视频） |

### 2.2 目标客户分层

| 客户层级 | 画像 | 月营销预算 | 月视频需求量 | 数量预估 |
|----------|------|-----------|-------------|----------|
| L1 小微卖家 | 个体户/夫妻店，月销 < 10 万 | 500-2000 元 | 20-50 条 | 约 1500 万 |
| L2 中小卖家 | 有团队，月销 10-100 万 | 2000-1 万 | 50-200 条 | 约 400 万 |
| L3 腰部商家 | 有品牌意识，月销 100-1000 万 | 1-5 万 | 200-500 条 | 约 80 万 |
| L4 头部品牌 | 品牌方/MCN，月销 1000 万+ | 5 万+ | 500+ 条 | 约 20 万 |

**种子阶段主攻 L2（中小卖家），拓展阶段升级到 L3（腰部商家）。**

### 2.3 客户痛点量化

| 痛点 | 现有成本 | AI 解决后 | 年化节省 |
|------|----------|-----------|----------|
| 招一个剪辑 | 8K-15K/月，月产 30 条 | 0 人力，日产 100 条 | 10-18 万 |
| 外包一条视频 | 300-2000 元/条 | 5-15 元/条 | 按 200 条/年 = 6-40 万 |
| 多平台适配 | 每平台单独做 | AI 自动裁剪比例/时长 | 3-5 万 |
| AB 测试素材 | 不够用 | 同一个品 10 种风格同时测 | 机会成本巨大 |

### 2.4 竞争分析

| 竞品 | 定位 | 弱点 |
|------|------|------|
| 可灵/Kling | 通用视频生成 | 不做营销场景，不解决分发 |
| Runway/Pika | 专业创作工具 | 贵，国内外卖家不会用 |
| 剪映/CapCut | 手动剪辑 | 需要人操作，不够自动化 |
| HeyGen/Synthesia | 数字人播报 | 单场景，不适合商品展示 |
| **Seedance Pro** | **电商营销视频全流程** | **专为卖货设计 + 数据闭环** |

### 2.5 差异化定位

不做"通用 AI 视频工具"，做**电商行业的视频工厂**：
- 内建电商模板（商品展示、使用教程、开箱、对比测评、促销倒计时）
- 接入商品链接自动抓取图片和详情 → 生成脚本 → 生成视频
- 视频发布后追踪播放量/转化率 → 反馈给 AI 优化下一批
- 支持主流电商平台一键铺货视频

### 3.2 核心功能

#### A. 智能商品转视频
1. 输入商品链接（淘宝/抖音/1688/Shopify）
2. AI 自动抓取商品图、标题、卖点、详情
3. 生成 3 套不同风格的脚本（种草型/硬广型/剧情型）
4. 用户确认/修改脚本
5. 批量生成 9:16 竖版短视频
6. AI 配音 + 字幕 + BGM 自动合成

#### B. 批量视频工厂
- 模板库：50+ 电商视频模板（按行业分类）
- 角色库：预设 AI 数字人形象
- 场景库：不同风格的展示场景
- 批量任务：一次提交 100 个商品，自动排队生成
- 后期编辑：裁剪、换音乐、改字幕样式

#### C. 数据闭环
- 视频发布后回传播放量/完播率/转化率
- AI 分析高转化视频的共性特征
- 自动生成"爆款模板"
- 下一批视频自动套用爆款模式

#### D. 多平台适配
- 自动生成 9:16（抖音）、16:9（YouTube）、1:1（淘宝主图视频）
- 不同平台的字幕样式/时长自动适配
- 一键发布（对接平台开放 API）

### 4.5 AI 模型路由策略（实际实现）

```javascript
// 实际代码 (seedance-server.js)
// 三种模型：Kling (可灵), Wanxiang (通义万相), Atlas Cloud

// 1. 可灵 Kling — JWT 签名认证
const KLING_ACCESS_KEY = process.env.KLING_ACCESS_KEY || '';
const KLING_SECRET_KEY = process.env.KLING_SECRET_KEY || '';

function getKlingToken() {
  // 生成 HS256 JWT: { iss: accessKey, exp: now+1800, nbf: now-5 }
  const header = Buffer.from(JSON.stringify({ alg: 'HS256', typ: 'JWT' })).toString('base64url');
  const payload = Buffer.from(JSON.stringify({
    iss: KLING_ACCESS_KEY, exp: Math.floor(Date.now()/1000) + 1800, nbf: Math.floor(Date.now()/1000) - 5
  })).toString('base64url');
  const sig = crypto.createHmac('sha256', KLING_SECRET_KEY)
    .update(header + '.' + payload).digest('base64url');
  return header + '.' + payload + '.' + sig;
}
// API: POST api.klingai.com/v1/videos/text2video 或 image2video

// 2. 通义万相 — 阿里云 DashScope API Key
const DASHSCOPE_API_KEY = process.env.DASHSCOPE_API_KEY || '';
// API: POST dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis
// Header: X-DashScope-Async: enable

// 3. Atlas Cloud — 透明代理
// API: ALL /api/v1/* → proxyToAtlas() → api.atlascloud.ai

// 自动降级路由
const PROVIDER_ORDER = ['kling', 'wanxiang', 'atlas'];

function tryFallback(providers, idx, params, cb) {
  if (idx >= providers.length) {
    cb(503, JSON.stringify({ error: { message: '所有 AI 模型提供商当前不可用' } }));
    return;
  }
  generateWithProvider(providers[idx], params, (code, data) => {
    if (code === 200) { cb(code, data); }           // 成功即返回
    else { tryFallback(providers, idx + 1, params, cb); }  // 失败降级
  });
}

// 前端可选择: Atlas / Kling / Wanxiang / Auto
// Auto 模式: 按 Kling → Wanxiang → Atlas 顺序尝试, 任一成功即返回
```

**成本结构（积分制）：**
| 模式 | 积分消耗 | 说明 |
|------|---------|------|
| Fast | **36 积分/次** | 默认，5 秒视频 |
| Standard | **54 积分/次** | 高质量 |
| 对比模式 | **72 积分/次** | 双视频 A/B 测试 |

```
    │   └─ 积分检查 (balance >= 36分)
    │
    ▼
┌──────────────────────────────────────┐
│  POST /api/generate (同步阻塞等待)     │
│                                      │
│  2. 后端校验 + 扣积分                  │
│     ├─ checkQuota() → 409 或通过     │
│     ├─ users[idx].balance -= 36      │
│     ├─ recordUsage() → video_usage   │
│     └─ 写 transactions.json          │
│                                      │
│  3. 模型路由 generateAuto()           │
│     ├─ provider=auto  → tryFallback  │
│     │   ├─ Kling    → POST api.klingai.com
│     │   ├─ Wanxiang → POST dashscope.aliyuncs.com
│     │   └─ Atlas    → proxyToAtlas()
│     └─ 等待 AI 返回 task_id           │
│                                      │
│  4. 失败退款                          │
│     └─ 若 AI 返回 >=400 → 退还积分     │
└──────────────┬───────────────────────┘
               │ 返回 task_id
               ▼
┌──────────────────────────────────────┐
│  5. 前端轮询 (3秒间隔, 最长10分钟)      │
│     GET /api/poll/:provider/:taskId   │
│     ├─ queued → 等待...               │
│     ├─ processing → 进度条更新         │
│     ├─ completed → 显示视频           │
│     └─ failed → 显示错误              │
└──────────────┬───────────────────────┘
               │ 视频 URL 返回
               ▼
┌──────────────────────────────────────┐
│  6. 可选后处理 (用户手动触发)           │
│     POST /api/video/post-process      │
│     ├─ 裁剪 (trim)                    │
│     ├─ BGM 叠加 (amix)                │
│     ├─ 水印 (drawtext)                │
│     ├─ 尺寸适配 (scale)               │
│     └─ FFmpeg child_process 执行      │
└──────────────────────────────────────┘
```

**与计划书异步流水线的主要差异：**
- 当前是**同步阻塞**模式，POST /api/generate 等待 AI 返回后才响应
- V2.0 改为异步：提交即返回 task_id，BullMQ 后台处理
- 无 Puppeteer 浏览器抓取（用简单 HTML 解析）
- 无 Claude API 自动脚本生成（用前端预设模板 + 3 种营销风格）
- 无 WebSocket/Webhook 通知（前端手动轮询）
- 无 Cloudflare R2 上传（内存暂存，5-10分钟过期）
- 后处理为手动可选操作，非自动触发

## 十、风险与应对

| 风险 | 概率 | 影响 | 应对策略 |

## 十一、核心优势与护城河

1. **电商行业 Know-how：** 不是通用工具，是专门为卖货设计的视频工厂
2. **数据飞轮：** 发布→数据回传→优化模板→更好视频→更多发布
3. **全栈自研可控：** 拥有全部代码，随时改底层
4. **先发优势：** 2026 年 AI 电商视频渗透率 < 5%
5. **零资金启动：** 轻资产模式，靠 API 按量付费
6. **切换成本：** 客户的模板/数据/历史在平台上，迁移成本高
